# vim — Vim 9.1 for Amix

Vim 9.1.0000, terminal only, under `/opt/amix`:
- `/opt/amix/bin/vim`, with `ex`, `view`, `vimdiff`, `rvim` and `rview` as hard links to it;
- `xxd`;
- the runtime in `/opt/amix/share/vim/vim91`: syntax files, filetype plugins, indent rules,
  colour schemes, the help files and the tutor;
- the pages `vim(1)` (with its aliases), `vimdiff(1)` and `xxd(1)`.

The stock `vi` is untouched; `vim` is found when `/opt/amix/bin` is on `PATH`.

    sh build/pkg/pkgbuild.sh userland/packages/ncurses     # first: vim links it
    sh build/pkg/pkgbuild.sh userland/packages/vim

Package: `vim`, category `editor`, set `extra`. Licence: the Vim licence (`LICENSE` in
`/opt/amix/doc/vim`). Built with GCC 14 (`-m68020-60 -mno-strict-align -O2`), the "normal"
feature set, with ncurses 6.6 linked statically (`BUILD_DEPENDS="ncurses"`).

**UFS only.** About 1800 files, 32 MB of runtime, and many runtime file names longer than s5's 14
bytes. The roll marks the package `APKG_FSTYPE=ufs`, and apkg refuses it on an s5 file system.

## Source

Vim 9.1.0000, the GitHub tag archive `https://github.com/vim/vim/archive/refs/tags/v9.1.0000.tar.gz`,
sha256 `8d2a74e3…b90e25d`. A tag archive is generated by GitHub on request, so our copy in the
amigaux/amix-distfiles archive (`vim-9.1.0000/v9.1.0000.tar.gz`), which the fetch falls back to, is
the pin of record. `AMIX_DISTFILES` names a local copy.

The configuration follows isoriano's amix-userland port (MIT, Ignacio Soriano): the feature set and
the `vim_cv_*` answers a cross build cannot measure (terminfo, `tgetent` returning zero, the tty
group and mode, `uname`).

## Patches

| Patch | Why |
|---|---|
| `01-vim-snprintf-ll.patch` | **Numbers printed as garbage.** `vim_snprintf()` formats each integer conversion by handing a one-conversion format to libc `sprintf`, and Amix's libc printf family reads `ll` as `l`: a `long long` takes 8 bytes on the stack, so the value and every later argument came out wrong. That covers every Vim Number (`:echo 5`, `"%lld bytes"`, `g CTRL-G`'s counts). The two `long long` cases now go through `snprintf`, which is libamixc99's on Amix and handles `ll`. |

## Build notes

- **ncurses** comes from its own build in the same build root
  (`$AMIX_BUILD_ROOT/ncurses/dest`). `pre_configure` stops if it is missing; `post_configure` checks
  `TERMINFO` and `-lncurses`.
- **`-include amix-decls.h`** declares `select` and maps `isinf` to gcc's builtin (Amix's
  `<math.h>` has no C99 `isinf`).
- **Not shipped:** `vimtutor`, a shell script that needs a POSIX shell (it uses `$(...)` and
  `mktemp`); start the tutor with `vim` and `:Tutor` instead. Also not shipped: the `lang/` message
  catalogues (NLS is off) and `tools/`.
- `xxd.1` splits its NAME entry over two lines; the stage hook joins it for `whatis.d`.

## Gates

`build.sh` passes:
- strict, with `-mno-strict-align` on every compile line;
- libacompat not linked;
- prototype == staged tree;
- the 060 gate.

The printf gate is reviewed (`AMIX_LL_PRINTF_REVIEWED`): Vim's binary carries `%lld` strings and
imports libc `printf`, but those strings are `vim_snprintf` formats, and after patch 01 they reach
libamixc99's `snprintf`. No `ll` format of Vim's own goes to libc `printf`, `fprintf` or `sprintf`
(checked by a grep of `src/*.c`).

## Tests

`tests/smoke.sh` runs on the box: it edits a file non-interactively through `ex` mode, checks
`vimdiff`'s argv[0] dispatch and the runtime's location, and dumps and reverts a file through `xxd`.
