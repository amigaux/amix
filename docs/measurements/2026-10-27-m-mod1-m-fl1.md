S4-70's host measurements (`docs/plan/stage-4.md`), from the exit set's
bytes: catalog 6e60a128, kern46m -82, kern30m -17, and each line's

## 1. M-MOD1 — the root set and the arena

The arena takes each root module's **file** (16-aligned) plus its
`bss=`, behind the `AXA1` directory and the manifest copy (C3-4). Today's
objects:

|---|---|---|---|---|---|
| z3660scsi 1.0.0-2 | 14 006 | 156 | 14 006 | 156 | 7 461 |
| a4091 1.0.0-5 | 10 486 | 68 | 8 887 | 68 | 5 518 |
| gayle 1.1.0-2 | 21 495 | 772 | 20 084 | 772 | 12 727 |
| ramdisk 1.0.0-1 | 4 630 | 816 | 4 630 | 816 | 2 938 |
| cdfs 1.0.0-1 (root only when promoted: a CD root) | 98 935 | 128 | 98 935 | 128 | 69 697 |
| a4000t-710, ufs, s5 | not built (S4-33, S4-40: carried to stage 5) | | | | |

**The generation of record.** k46: the four controllers' modules and
the manifest copy need **53 996 bytes** of the 393 216. That is gate 4's
own figure on -82's generation, taken by raising z3660scsi's `bss=` by
399 844 and reading `need 453 840` back. k30's set is 3 010 bytes smaller
(a4091 and gayle).

**The largest generation a box can compose today**: every controller
module plus cdfs promoted to root (a CD root), about 152 KB of files and
bss plus the directory and a 2 to 3 KiB manifest copy. That is about 155
KB, 40 % of the arena.

**The arena holds.** 0x60000 (384 KiB) stays on both lines: twice the
largest set today is about 310 KB, under 384 KiB. The stage-5 modules
add the 53C710 (the a4091 object's size, about 10 KB) and **one** root
filesystem per generation: only the root's filesystem is promoted to
root class (C4-6 §1). With ufs as large as cdfs, the set stays under
192 KiB, so the 2× rule still gives 384 KiB. Re-measure when S4-40's
objects exist.

What is left in the floor: the core, the stock controllers spec 70
keeps (the A3000 WD, the A590/A2091: `root=mobo:a3000-wd,zorro:0202:01,
zorro:0202:03` in both sidecars), and **ufs and s5** (`rootfs=ufs,s5`).
The root-class controllers (z3660scsi, A4091, Gayle) and cdfs have left
it. k30 is 78 016 bytes smaller than stage 3's: the static cdfs and the
controllers left. k46 is 11 855 bytes larger: the core's stage-4 patches
outweigh what left.

**M-FL1 is final only after S4-43** (the kernels without ufs and s5,
carried to stage 5 with S4-40). Re-measure there. The expected saving is
about the k30 ufs and s5 objects' 95 KB allocated (stage 3 §5).
