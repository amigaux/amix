# U16 and M-ABI2 — the module kernels of the final cut (2026-10-26)

- **Measurements:**
  - U16 (90 §3): the 040/060 port's relocation and page-geometry checks
    with the arena's zero block in `.data`;
  - M-ABI2 with the block (90 §3): a `brel` that carries the symbol block,
    bound by the loader's relocator, with the identity record intact.

  Both belong to stage-3 plan item S3-40, and `2026-10-26-m-reg1-m-abi1.md`
  §6 left both open.
- **Class:** bench (host computation).
- **Inputs:** the two module kernels built from amix-dlm `f5ce731` (core
  patches 0001–0020):
  - k46: KD060-Z, build `68060-261026-56`, 2 430 872 bytes, `ET_REL`,

  - k30: K030-U, build `68030-261026-01`, 1 715 476 bytes, `brel`,

    from amix-kerntools' relink kit.
- **Tools:**
  - U16: the port's own gates, run by the port on its build (S3-20);

    and a check of `AXK1` in the bound image, as boot2 does it.

## 1. U16 — the port's gates over the k46 module kernel

The port ran its relocation and page-geometry gates on the emitted image
(the form that ships). The image carries the 0x60000-byte arena in `.data`:
`arena=0x00129cc4 0x00060000`.

| Gate | Result |
|---|---|
| `check_relink_relocs` | TOTAL 0 |
| layout | `.text` 0x10b764 at file offset 0x34; `.data` 0x7fd74 at 0x10b798, contiguous with `.text`; `.bss` 0x11750 |
| the b2 flip | COPYBACK |
| k0 gates | all pass |
| emit | passes; two runs byte-identical |
| `scan060` | clean, 12 528 instructions |
| weak symbols | none; undefined only `etext`, `edata`, `end` (the loader supplies them) |

A reproducibility twin (build -57) matches through the core stage and
differs from it in one byte (the build id digit), with the same `abi=`.

**U16 holds.** The arena's zero block changes nothing the port's gates
check: it is plain `.data`, relocated like the rest.

## 2. M-ABI2 — the symbol block through `brel` and the loader

**Relocations.** The `brel` form keeps one 8-byte pair per relocation:

| K030-U | pairs | |
|---|---|---|
| static kernel of record (2026-10-26 M-ABI2, format) | 29 539 | |
| module kernel, final cut | 30 487 | 29 359 relocated by the base, 1 128 absolute |

The 948 more pairs are the core's own relocations, plus the 78-name block
(one `R_68K_32` per name and two for its header). That costs 7 584 bytes
of file.

**Binding.** `axrel` binds each kernel at 0x00200000 and at 0x07F00000;
k46 is bound with PC-relative relocations allowed, as boot2 binds an
`ET_REL` kernel. Then `AXK1` at the sidecar's `ident=` is checked in each
bound image, as boot2 checks it: magic, version, the check word, the kabi
tag against the sidecar's `kabi=`, line, arena offset and capacity, symbol
block offset and size, and flags. The arena must also be all zero.

| Kernel | `AXK1` | kabi | arena | symbol block | at 0x00200000 | at 0x07F00000 |
|---|---|---|---|---|---|---|
| K030-U | 0x0010732c | k30.1.0 | 0x0010736c, 0x60000, zero | 0x0010694c, 2 524 bytes | ok | ok |
| KD060-Z | 0x00129c84 | k46.1.0 | 0x00129cc4, 0x60000, zero | 0x00189cc4, 2 584 bytes | ok | ok |

The post-link gate (C3-2 §2, `tools/ksymgate.py`) passed 12 of 12 on
both kernels at both bases in the builds that produced them. Every listed
name looks up to its own address, kind and tier.

**M-ABI2 holds with the block.** The `brel` carries the block's
relocations one for one, the loader binds it anywhere, and the identity
record survives the binding.
